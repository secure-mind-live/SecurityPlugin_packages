# Contributing to SecurityPlugin

Thanks for your interest in making AI agents safer.

## Getting Started

```bash
git clone https://github.com/secure-mind-live/SecurityPlugin_packages.git
cd SecurityPlugin_packages
pip install securityagent-core
```

## How to Contribute

1. **Open an issue first** — Describe the bug or feature before writing code. This saves everyone time.
2. **Fork and branch** — Create a branch from `main` with a descriptive name (e.g., `fix/false-positive-ssh-add`).
3. **Keep PRs focused** — One fix or feature per PR. Small PRs get reviewed faster.

## What We're Looking For

- **False positive fixes** — If SecurityPlugin blocks a legitimate action, that's a high-priority bug.
- **New detection patterns** — See a real-world exfiltration technique we don't catch? Open an issue.
- **Integration guides** — Better setup docs, platform-specific instructions.
- **Bug reports** — Anything that doesn't work as expected.

## Security Vulnerabilities

If you find a security vulnerability in SecurityPlugin itself, please **do not open a public issue**. Email the maintainers directly. Responsible disclosure helps keep everyone safe.
